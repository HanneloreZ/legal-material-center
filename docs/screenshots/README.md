# Screenshot Legal Studio

根据 ScreenshotLegalBench_v2_eval 的标注字段重新实现的截图合成工具。不是旧截图生成器的恢复版。原仓库和原数据保持不变。

## 运行

无需安装依赖：

```sh
cd dist
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765/ 。请通过 HTTP 使用，直接双击 HTML 可能因 ES module 限制无法加载。

## 功能

- 微信风格单聊/群聊截图，文字、时间、转账、收款、文件、语音和撤回提示。
- 转账金额、备注、待收款/已收款/已退还状态。各消息独立编辑，金额或状态不会自动联动；请确保同一交易的消息和标注一致。
- Unicode emoji 与常见微信方括号表情映射（如 `[微笑]`、`[抱拳]`）；原文保留在标注中，图像以近似 Unicode 表情显示。
- 表情包上传 PNG/JPG/WebP（≤3 MB），自动缩至最长边 512 px，保留透明背景；按静态帧绘制。
- 法律意图、关系与分析人工填写；不调用模型，也不会自动判断法律结论。
- PNG、单独 JSON、ZIP 数据包；375/390/402/430 逻辑像素与 1/2/3 倍导出。
- 本机浏览器自动保存、项目 JSON 保存及恢复、批量 cases JSON 导入。
- 1–100 个确定性模板变体，姓名和金额按种子替换；不是新案情生成或人工法律校验，需复核文字与标签。

## 数据格式

单项目参考网页「保存项目」；批量参考「下载批量导入示例」。导入支持单项目、`{project: ...}`、项目数组、`{cases: [...]}`。旧评测仓库仅有标注，缺少完整渲染配置，不能直接作为本工具项目导入。

每个数据包：

- `images/sample_001.png`
- `annotations/sample_001.json`：尺寸、消息、坐标、标注、完整项目配置
- `extracted_all_rect_attrs.json`：沿用旧评测字段的数组，包括 `image_number/image_tail/tool/label/answer/x/y/width/height/order`，另加 `message_id`。新增 `text/sticker/voice/timestamp/recall` 等标签，旧评测器可能需要筛选标签。
- `projects.json`：可重新导入的项目列表，包含上传素材
- `manifest.json`：样本索引及合成属性

坐标以导出 PNG 像素为单位，原点在左上角。`rect_attrs` 不包含导航栏等非评测区域；标注框仅用于预览。

## 实现范围

用 Canvas 重建接近微信的视觉样式，非微信官方客户端的像素级复刻。iOS/Android 选项目前只区分状态栏字体，不模拟完整系统差异。emoji 字形取决于操作系统字体。语音仅生成消息外观及转写标注，不合成音频；文件卡片仅含显示信息，不包含文件内容。没有原始截图、自动 OCR、旧数据全文重建、服务器数据库或多人协作功能。

运行时图片与内容均在浏览器内处理，不上传服务器。项目 JSON 和浏览器草稿会包含用户上传的表情包。合成图片默认显示标记，所有标注文件均保留 `synthetic: true`。

## 群聊和头像

参与人可扩展到 20 名（其中 1 名己方），每条消息可独立选择发送人。支持逐人导入头像、分别编辑微信昵称与联系人备注，截图优先显示备注。备注示例可一键混排中文、英文、emoji、职位与项目名。头像做中心方形裁切；原素材保存在项目 assets 中。`structured_info.participants` 同时保留原始昵称、备注和头像素材 ID，避免把显示名当作唯一身份。

## 文档状态和引用

文档卡片支持发送中、已发送、下载中、已下载、发送失败和过期状态；发送/下载中可设置进度。可从本地文件提取名称和大小，不读取正文，不上传或包含文档二进制内容。

文字回复可以引用其他消息，包括文件和转账。截图在回复气泡下方的独立灰色块中显示原发送人和摘要，`structured_info.messages[].quote` 及 `quoted_message` 标注保留引用关系；摘要最多显示 3 行。文档状态另存为 `file_status` 标注。

验证：运行 `npm test`（无需安装依赖）可检查坐标、导出倍率、群成员身份、文件状态、引用关系及 ZIP 结构。真实 Canvas 字体和 PNG 导出仍需浏览器检查。

## 撤回与语音通话

撤回提示支持自定义文字、自己撤回和指定成员撤回。语音通话记录独立于语音消息，可设置已接通、已取消、对方未接听、已拒绝、对方忙线及 `mm:ss` 时长；只合成记录外观，不发起通话或生成音频。

## CC0 头像库（1.1）

点击参与人的头像打开图库，或点「随机头像」给现有成员混合分配。

内置 30 张头像：风景、动物、花草来自 Wikimedia Commons 的 CC0 文件，插画和像素来自 DiceBear 的 Lorelei、Notionists、Pixel Art CC0 风格。清单在 `dist/avatar-catalog.json`，包含作者、来源页面、许可链接及下载地址。离线头像与网站同源，不依赖外部图片加载。

支持在线搜索 Wikimedia Commons；搜索结果按单文件 `LicenseShortName=CC0` 元数据再次过滤。更多插画调用 DiceBear HTTP API，并使用随机序号作为种子，避免发送昵称等个人数据。在线搜索仅发送搜索词；不发送对话内容。外部服务不可达时，内置图库和本地上传仍可使用。

选中的头像转为本地 PNG data URL，来源记录在 `assetCredits` / `asset_credits`，ZIP 另含 `asset_credits.json`。在线文件的授权依赖来源元数据，不把普通“免费图库”统称为公共领域。现成动漫作品、角色和商标不在内置图库中。

重新下载可运行 `python3 scripts/cache-avatar-library.py`（需联网）。使用 `CC0 1.0` 是来源的公共领域奉献声明，不保证作品在任何用途、任何司法辖区均无其他权利限制。

## 参考图比例（1.1）

画面设置 → 字体与截图比例 → 采用参考图比例：402×874 逻辑像素、3× 导出（1206×2622）、16px 正文、22px 行高、41px 头像。固定屏幕高度会从底部显示最近消息；被裁切的坐标按可见区域截取。长图模式仍可保留完整对话。

优先使用设备已有的 PingFang SC 字体；没有该字体时会回退系统字体，不分发苹果字体文件。字号、行高、头像边长、消息间距、字体和输入栏模式可调。此预设参考了用户截图的布局比例，未将用户的私人截图、消息或头像打包、上传或加入示例。不同系统的字体栅格化仍可能存在差异。

示例对话已改为短句和日常口吻，结合发言人的角色区分请求、同意与催促。借款示例会先提出延期请求，再由出借人回应；人工标签随之调整。编辑规则见 `DIALOGUE_STYLE.md`。刷新后重新选择场景模板可载入新版，已有草稿和用户导入的内容保留原文。
