# 示例对话的写法

对话写成双方正在微信里办事，别让每个人都像在写情况说明。每条只说眼下要紧的事，金额、日期、原因不必反复复述。

先看关系和处境。借款人请求延期时，要留出对方同意或拒绝的空间，如“剩下的能不能缓到月底？”；出借人可以答应、追问或催促。请求发出不等于已经谈妥，法律意图标签也要区分“请求延期”和“同意延期”。

上下级、买卖双方、朋友之间的语气可以不同。负责人安排工作可以直接，求对方帮忙的人要有请求的口气。少量语气词用在合适的地方，不给所有人套同一种客气话。

口语化可以压缩重复信息，不随意改变金额、期限、人物身份及先后顺序。关键约定可以分几条逐渐说清，别让一条消息交代完整个案情。语音转写也按实际说话的方式写。

现有四组模板已按这些规则人工编辑。批量功能仍只替换姓名与金额，不调用模型重写用户输入或自动判断语气。
